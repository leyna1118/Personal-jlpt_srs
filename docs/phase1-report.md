# Phase 1 完成報告:資料處理

## 做了什麼

1. 從 5mdld/anki-jlpt-decks 抓下原始資料(`notes.csv`,10,634 詞條),
   過濾出 N1/N2/N3 三個等級,共 **9,070 個單字**。
2. 修好「單字」欄位裡殘留的注音符號格式問題(例如「石 鹸[けん]」還原成「石鹸」),
   影響約 175 個字,已全部修正,確認沒有殘留。
3. 只保留繁體中文意思欄位,簡體中文欄位不使用。
4. 每個字整理出:漢字、讀音、詞性、繁中意思、補充說明(若有)、
   等級(N1/N2/N3)、頻率(高/中/低頻)、例句(日文+中文翻譯)、
   相關詞、反義詞(資料裡本來就有標注的部分)。
5. 抓出自動詞/他動詞配對:先用「同一個漢字字根、一個自動一個他動」的邏輯抓出候選,
   對於只有一組候選的(84組)直接採用;對於同一個字根有多個候選、容易配錯的(28組),
   我用日文知識人工挑出正確的配對組合,並排除兩組明顯配不出正確答案的(「見」「追」開頭的那兩組,
   湊出來的候選其實語意不相關,不勉強配對)。最終確定 **116 組自動詞/他動詞配對**。
